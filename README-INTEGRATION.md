# Integrating These Files

Copy the other files in this directory to the repository root. Before
publishing them, replace every bracketed placeholder:

- `[LEGAL SURNAME]`
- `[LEGAL CONTACT EMAIL]`
- `[TRADEMARK CONTACT EMAIL]`

If Brewzora Studios later becomes a legal entity and receives ownership of the
copyrights and trademarks through appropriate written assignments, update the
owner language only after that transfer is effective.

Add this section to the project README:

```markdown
## Licensing

The ZACS specification and documentation are licensed under the
[Creative Commons Attribution 4.0 International License](LICENSE.md).

Software, build scripts, and validation tools are licensed under the
[MIT License](LICENSE-CODE.md).

Contributors retain copyright in their contributions and license them under
the license applicable to the material modified. See
[Contribution Licensing Terms](CONTRIBUTING-LICENSES.md).

ZACS™ and Zero Ambiguity Contribution Standard™ are trademarks. The content
licenses do not grant trademark rights. See the [Trademark Policy](TRADEMARKS.md).
```

Link `CONTRIBUTING-LICENSES.md` prominently from the main `CONTRIBUTING.md` and
require contributors to accept it before submitting a pull request. A GitHub
pull-request template can include:

```markdown
- [ ] I have read and agree to the repository's Contribution Licensing Terms.
- [ ] I have the right to submit this contribution under the applicable
      repository license.
- [ ] I have disclosed third-party material and automated generative assistance
      as required by project policy.
```

These files are a practical starting point, not a substitute for advice from a
lawyer licensed in the relevant jurisdiction. Obtain legal review before a
1.0 release, trademark filing, certification program, or transfer of ownership.
